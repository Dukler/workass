outsweep() lee lastActivity sin tomar mu · marca hibernación fuera del lock

La race está entre sweep() y Touch(). El barrido lee c.lastActivity sin tomar mu, decide que el chat está inactivo y recién entonces adquiere el lock para hibernarlo. Si Touch() corre en esa ventana, el reaper hiberna un chat que acaba de recibir trabajo.

go 
// sweep corre cada tick; la lectura de lastActivity queda FUERA del lock.
func (r *Reaper) sweep() {
    now := time.Now()
    for _, c := range r.chats() {
        if now.Sub(c.lastActivity) < idleTTL {
            continue
        }
        c.hibernate() // ← puede pisar un Touch() concurrente
    }
}
