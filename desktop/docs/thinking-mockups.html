“Thinking” siempre visible — mockups

Problema actual: la tarjeta de razonamiento vive arriba del mensaje y, cuando llegan mucho texto y tool-calls, queda empujada fuera de vista. Estas son 3 formas de mantener el pensamiento SIEMPRE visible sin robar protagonismo. Inspirado en Codex (resumen colapsable), Claude Code (línea de estado viva con verbo + tiempo) y opencode / pi (tail compacto en su lugar).
