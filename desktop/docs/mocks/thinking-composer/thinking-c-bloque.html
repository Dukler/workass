Por qué no es un corte. El recorte de hoy termina en la nada: el lector no sabe si la frase terminó o si el renderer la cortó. Acá la cola siempre termina en un cursor que parpadea, dentro de un bloque con regla, color y tamaño distintos del texto de respuesta. Una frase a medias se lee como una frase en curso, que es lo que es. El costo es altura: son cinco líneas de chat mientras el modelo piensa. El encabezado se pliega con un clic y recuerda la elección.
