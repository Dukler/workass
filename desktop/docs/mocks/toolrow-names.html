Sólo cambian las filas individuales (sueltas y dentro de un grupo). El resumen plural “1 comando · 1 subagente · …” no se toca.

El nombre es el identificador crudo de la herramienta: Bash, mcp__…__…, o el comando entero de Codex ocupando toda la línea.
