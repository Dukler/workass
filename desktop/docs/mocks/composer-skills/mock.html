Composer — comandos, agentes y estilos

El Agent SDK reporta al inicio de sesión los slash-commands, los subagentes y los estilos de salida del usuario; hoy el composer los ignora. Este mock agrega un popup arriba del composer: / abre Comandos, @ abre Agentes, y las pestañas cambian de catálogo. Elegir inserta texto — nunca envía.

A — "/" recién tecleado · catálogo completo, primera fila activa
/deploy Compilá y promocioná el daemon a prod ⏎
/revisar-prRevisá el PR abierto con la checklist del repo
/buscar-bugRastreá un bug del síntoma al commit culpable
/resumen-diarioArmá el resumen de Teams y Jira de hoy
/probar-acpCorré las sondas ACP contra el mock oracle
/empaquetar-y-promocionar-daemon-a-la-laptop-de-prodFirma, package y handoff, todo de una
/recargar-uiRecargá el renderer sin relanzar Electron
/commitCommit con recibos: comando + salida
↑↓ navegar ⏎ usar ⇥ completar esc cerrar
/

El popup vive adentro de .compwrap, pegado arriba del box y con su mismo ancho. Con el popup abierto, ⏎ elige la fila activa (inserta /deploy␣ y cierra) — no envía. El nombre largo clampa con ellipsis; la descripción también.

B — "/re" tecleado · filtro fuzzy, navegado con ↓ a la segunda fila
/revisar-prRevisá el PR abierto con la checklist del repo
/recargar-ui Recargá el renderer sin relanzar Electron ⏎
/resumen-diarioArmá el resumen de Teams y Jira de hoy
/probar-remotoProbá la conexión con la fleet remota
↑↓ navegar ⏎ usar ⇥ completar esc cerrar
/re

Fuzzy por subsecuencia, no solo prefijo: /re también encuentra probar-remoto por límite de palabra. Los caracteres matcheados llevan el acento verde (único uso del verde en el popup); el resto del nombre queda en tinta. Sin resultados → el popup se cierra solo, no muestra un cascarón vacío.

C — "@" tecleado · picker de agentes (misma superficie, pestaña Agentes)
@general Investiga en paralelo y te trae recibos Fable 5 ⏎
@revisor-de-pr Gate de revisión: bugs primero, estilo después Sol · xhigh
@explorador-repo Recorre el código, solo lectura, cero riesgo Terra
@documentador Mantiene docs y changelog al día Opus 4.8
@verificador-de-contratos-wire-y-landmines-acp Chequea invoke/reply/event y las minas ACP Fable 5
↑↓ navegar ⏎ usar ⇥ completar esc cerrar
@

Cada fila trae el modelo del subagente a la derecha, mono y clampado a 12ch — un nombre de modelo larguísimo no rompe la fila, y el nombre de agente kilométrico clampa igual que los comandos. Elegir inserta @general␣ y el resto del mensaje es la tarea para ese agente. Las pestañas también se clickean: desde / podés saltar a Agentes sin borrar nada.

D — catálogo vacío · "/" es texto literal, no aparece nada
/deploy a la laptop de prod

Si el provider no reporta comandos (mock, provider viejo, sesión fría), el composer queda exactamente como hoy: sin popup, sin cascarón "Sin comandos", sin toast. ⏎ envía el texto tal cual. Lo mismo por pestaña: sin agentes → la pestaña Agentes no existe y @ es un arroba común.
